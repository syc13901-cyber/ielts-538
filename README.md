# 538 考点词 — 雅思阅读同义替换背词工具

刘洪波《雅思阅读考点词真经》538 个考点词的交互式背词工具，纯 HTML 打开即用。

## 功能

- **背诵模式（筛选式）**：答对的词本轮不再出现，答错或点「不认识」的词排入队尾重背，直到全部通过才算完成一轮；轮次进度自动保存，刷新页面不丢
- **「不认识」按钮**：背诵与测试时遇到没把握的词可一键标记，自动进入生词本
- **串联记忆（生词本）**：答错与「不认识」的词在批改当下立即收录（标签页角标实时计数），集中列举 + 一键串记（同样采用筛选式）；支持逐词「✕ 删除」与"已掌握"移出，一次答对的词可批量移出
- **测试模式**：答错会显示正确答案并稍作停留；成绩单 + 错题本，支持"只测错题""串记错题"
- **单词发音**：点 🔊 朗读当前单词（需浏览器支持语音合成）
- **键盘快捷键**：`1-4` 选选项，`D` 或 `0` = 不认识，`空格`/`回车` = 继续 / 下一题
- **三组切换**：第1组 20 个核心词（命中率 90%）→ 第2组 100 个进阶词（命中率 60%）→ 第3组 258 个高分词
- **进度记忆**：背诵轮次、生词本自动保存到浏览器本地，关闭再打开继续

## 使用方法

1. 下载整个文件夹（`index.html` + `data.js` 都要在同一个目录里）
2. 双击 `index.html`，浏览器自动打开
3. 选择组别 → 开始背诵或测试

## 技术

纯前端，零依赖。数据通过 `<script>` 标签加载，无需服务器。

## 数据来源

刘洪波《剑桥雅思阅读考点词真经（机考笔试综合版）》538 个考点词，含第 1 类（20 个核心词）、第 2 类（100 个进阶词）、第 3 类（256 个高分词 + 部分同义替换词）。
